GaonEats Demo — Windows quick start

1. Extract GaonEats_Demo.zip to a folder.
2. Open the folder.
3. Double-click index.html. It opens in Chrome/Edge.
4. Try the menu filters, search, Add buttons, quantity controls, demo checkout and Restaurant/Admin demo tabs.

Important:
- This is a browser-based interactive prototype, not a published Android/iPhone app.
- Orders are stored only in the current browser session and are not sent to restaurants.
- No live payments, maps, login, SMS, backend, delivery tracking, or app-store build is connected.
- Do not enter sensitive personal information. Use sample/demo details.
- Next phase for real launch: connect database/auth, restaurant accounts, secure order storage, payment and delivery workflows, then build/test Android and iOS packages.
